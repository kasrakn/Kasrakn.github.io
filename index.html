Transcriptomics Ongoing

Machine learning for high-dimensional RNA-seq data

I train machine learning models that find meaningful patterns in bulk RNA-seq gene expression data, alongside bioinformatics methods such as differential expression analysis. The current application is a rat study of how kynurenine changes gene expression.

The core challenge is p ≫ n. Tens of thousands of genes are measured on a small number of samples, so models have to be regularized and interpretable to find real biological signal instead of noise.

Projects

Deep learning · Sleep-EDF

Near real-time sleep stage classification

A deep learning model that classifies sleep stages from EEG on the Sleep-EDF dataset. A CNN extracts features from each 30-second epoch, then an LSTM and multi-head attention layers learn patterns within and across epochs. It works with a 5 to 10 minute delay instead of needing a full night of recording, and it is small enough to deploy on edge devices.

Genomics · Algorithms

MRA: every tandem repeat in one scan of DNA

Tandem repeats make up about 3% of human DNA, mutate easily, and are linked to diseases such as neurodegeneration. Existing tools each cover one class of repeat. The Multi-head Reader Arm (MRA) algorithm finds exact and inexact repeats of every pattern length in a single linear-time pass: a base head and one head per pattern length move along the sequence together, comparing characters as they go.

On human chromosomes 1 to 5 (181 to 249 million bases), MRA ran faster than TRF, Mreps, Perf and Kmer-SSR while using almost no extra memory. Built at Ferdowsi University with Stanford University collaborators.

  • O(n) algorithm
  • Genomics
  • Human genome
