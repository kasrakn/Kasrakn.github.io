# Kasra Korminejad — personal site

Static site, no build step. `index.html` is the whole page; `kasra.jpg` and `Kasra_Korminejad_Resume.pdf` sit next to it.
The resume PDF is the same page printed (print styles live in `index.html`).

Deploy: push these files to a GitHub repo and enable Pages (Settings → Pages → Deploy from branch → `main` / root).
A repo named `Kasrakn.github.io` is served at https://kasrakn.github.io.
